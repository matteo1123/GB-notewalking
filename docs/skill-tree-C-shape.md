# The C Shape Mastery Tree
### CAGED System — C Branch
> *"Every great warrior knows their territory. The C shape is your first domain."*

---

## Overview

This skill tree maps everything a player must conquer to achieve **true mastery of the C shape** within the CAGED system. The tree is structured in **Tiers** — you cannot unlock a tier until the one before it is complete.

The core philosophy:
1. **Divide** the shape into its two string groups (High / Low)
2. **Drill** each group through Arpeggio → Scale → Sequence → Legato
3. **Combine** each group into a Realm Capstone
4. **Unite** both realms into the Full Shape
5. **Transcend** with advanced knowledge and expression
6. **Claim** the title of C Shape Guardian

---

## The Shape at a Glance

The C shape chord (open position, key of C):

```
   E  A  D  G  B  e
   x  3  2  0  1  0
```

**Chord tones:** C (root) — E (major 3rd) — G (perfect 5th)

**Root locations within the shape:**
- String 5 (A), fret 3 = C  ← primary root
- String 2 (B), fret 1 = C  ← secondary root

**Scale: C Major (Ionian) in first position**
```
e  |--0--1--3--|
B  |--0--1--3--|
G  |--0--2-----|
D  |--0--2--3--|
A  |--0--2--3--|
E  |--0--1--3--|
```
*Notes per string: e=E,F,G | B=B,C,D | G=G,A | D=D,E,F | A=A,B,C | E=E,F,G*

## Tier 0 — Foundation Stone

### [C-00] The C Chord
> *"You cannot rule a territory you have never entered."*

**Type:** Foundation  
**Requires:** Nothing — this is where the journey begins

**What you learn:**
- The open-position C chord voicing: `x32010`
- Which fingers go where (standard fingering: ring=A3, middle=D2, index=B1)
- The names of the notes sounding: C (root), E (3rd), G (5th), C, E
- Where the two roots live: string 5 fret 3, string 2 fret 1
- How to play it cleanly — every note rings, no buzzing, no muting

**Practice Protocol:**
1. Finger the chord and pluck each string individually, confirming all ring cleanly
2. Strum slowly, listening for clarity
3. Name each string aloud as you pluck it: "G... C... E... G... C... E"
4. Mute and re-finger 10 times, aiming for smooth, clean arrival

**Mastery Test:**
- [ ] Chord rings cleanly with zero buzzing
- [ ] You can name all 6 strings (and which are muted) from memory
- [ ] You can point to both root notes without hesitation
- [ ] You understand this is a *moveable shape*, not just one chord

**Unlocks:** [C-1H] High Gate, [C-1L] Low Gate

## Tier 1 — Realm Division

The C shape is split into two **string kingdoms**. A warrior must master each kingdom before they can command the whole.

---

### [C-1H] High Gate — The High Realm (Strings 1·2·3)
> *"The treble side sings. Learn its language."*

**Type:** Gateway  
**Requires:** [C-00]

**String group:** e (1), B (2), G (3)

**Scale fragment on high strings:**
```
e  |--0--1--3--|    E  F  G
B  |--0--1--3--|    B  C  D
G  |--0--2-----|    G  A
```

**Notes available:** G, A, B, C, D, E, F, G — all 8 notes of C major, highest register

**Chord tones on these strings:**
- G string, open (fret 0) = **G** (5th)
- B string, fret 1 = **C** (root)
- e string, open (fret 0) = **E** (3rd)

**What you learn here:**
- The geography of the top 3 strings within the C shape
- Which dots on these strings belong to C major
- Which of those dots are chord tones vs. passing tones

**Mastery Test:**
- [ ] Can name every note on strings 1-2-3 within the C shape position
- [ ] Can identify the chord tones (C, E, G) among those notes

**Unlocks:** [C-2H-A], [C-2H-S], [C-2H-Q]

---

### [C-1L] Low Gate — The Low Realm (Strings 4·5·6)
> *"The bass side rumbles. It carries the weight of the shape."*

**Type:** Gateway  
**Requires:** [C-00]

**String group:** D (4), A (5), E (6)

**Scale fragment on low strings:**
```
E  |--0--1--3--|    E  F  G
A  |--0--2--3--|    A  B  C    ← Root lives here (fret 3 = C)
D  |--0--2--3--|    D  E  F
```

**Notes available:** D, E, F, G, A, B, C — full lower register of C major

**Chord tones on these strings:**
- E string, fret 3 = **G** (5th)
- A string, fret 3 = **C** (root) ← primary root of the entire shape
- D string, fret 2 = **E** (3rd)

**What you learn here:**
- The geography of the bottom 3 strings within the C shape
- That the primary root of the C shape lives on string 5
- Which frets are chord tones vs. scale color tones

**Mastery Test:**
- [ ] Can name every note on strings 4-5-6 within the C shape position
- [ ] Can identify the chord tones (G, C, E) on the low strings without hesitation
- [ ] Knows which string and fret is the primary root

**Unlocks:** [C-2L-A], [C-2L-S], [C-2L-Q]

## Tier 2 — First Weapons (Both Realms in Parallel)

Each realm has three Tier 2 nodes. **All three must be completed before the Tier 3 Legato node unlocks.**

---

### [C-2H-A] High String Arpeggio
> *"Separate the chord tones from the noise. Let only the essential notes speak."*

**Type:** Technique  
**Requires:** [C-1H]

**The Pattern:**
```
e  |--0--|    E (3rd)
B  |--1--|    C (root)
G  |--0--|    G (5th)
```
*Ascending (5th → root → 3rd): G → C → E*  
*Descending (3rd → root → 5th): E → C → G*

**The Core Motion:**
- Play one note per string, strictly alternating pick or fingers
- Ascending: start on G string (fret 0), then B string (fret 1), then e string (fret 0)
- Descending: reverse the path
- No open-string ringing into the next — control your note duration

**Expand it:**
- 1 octave: G → C → E (strings 3 → 2 → 1)
- Extended: add the lower octave root (B string fret 1 = C), then come back up
- Pattern variations: G-C-E-C-G / E-C-G-C-E (pendulum)

**Practice Protocol:**
1. Start slowly (60 BPM). One note per click. Every note clean.
2. Add a metronome. Aim for 8th notes, then 16th notes.
3. Practice ascending only, then descending only, then combined.
4. Try fingerpicking: thumb on G, index on B, middle on e

**Mastery Test:**
- [ ] Can play G → C → E → C → G cleanly at 80 BPM (16th notes)
- [ ] Can name each note as you play it
- [ ] Sounds musical — not mechanical

**Unlocks:** Required for [C-CAP-H]

---

### [C-2H-S] High String Scale Run
> *"Learn the full melody of the shape. Straight road, both directions."*

**Type:** Technique  
**Requires:** [C-1H]

**The Pattern:**
```
e  |--0--1--3--|    E  F  G
B  |--0--1--3--|    B  C  D
G  |--0--2-----|    G  A
```

**Ascending:** G - A - B - C - D - E - F - G  *(strings 3 → 2 → 1, low fret to high fret)*  
**Descending:** G - F - E - D - C - B - A - G *(reverse)*

**Picking options:**
- Strict alternate picking (recommended first)
- Economy picking (sweep into position changes)
- Hybrid picking

**Practice Protocol:**
1. Ascending first — confirm each note rings, no buzz, no muting
2. Descending second
3. Continuous loop: ascend to top G on e string fret 3, descend back to G on G string
4. Target tempos: 60 → 80 → 100 BPM (16th notes)
5. Say the note names aloud while playing slowly

**Mastery Test:**
- [ ] Ascending + descending in one smooth phrase at 90 BPM (16th notes)
- [ ] Can start and end on any note within the fragment
- [ ] Zero hesitation on position shifts between strings

**Unlocks:** Required for [C-CAP-H]

---

### [C-2H-Q] High String Sequence
> *"The warrior who only walks in straight lines is predictable. Learn to move in patterns."*

**Type:** Technique  
**Requires:** [C-1H]

Sequences break the scale into repeating melodic patterns, creating motion and interest.

**Sequence A — Groups of 3 (ascending):**
```
Play 3 notes up, step back 2, play 3 up, step back 2...
G  A  B  |  A  B  C  |  B  C  D  |  C  D  E  |  D  E  F  |  E  F  G
```

**Sequence B — Diatonic 3rds (ascending):**
```
Skip every other note of the scale:
G - B  |  A - C  |  B - D  |  C - E  |  D - F  |  E - G
```

**Sequence C — Groups of 4 (ascending):**
```
G  A  B  C  |  A  B  C  D  |  B  C  D  E  |  C  D  E  F  |  D  E  F  G
```

**Practice Protocol:**
1. Learn Sequence A first — it's the most natural melodically
2. Count out loud: "1-2-3, 1-2-3" to feel the grouping
3. Then Sequence B — this one requires more mental effort
4. Then Sequence C — groups of 4 shift where the beat lands, creating syncopation
5. Practice each both ascending AND descending

**Mastery Test:**
- [ ] All three sequences, ascending, at 80 BPM (16th notes)
- [ ] Sequence A descending at 80 BPM
- [ ] Can make any of these sequences sound like actual *music*, not just exercise

**Unlocks:** Required for [C-CAP-H]

### [C-2L-A] Low String Arpeggio
> *"The foundation of the shape speaks in roots and power. Learn to walk the bass."*

**Type:** Technique  
**Requires:** [C-1L]

**The Pattern:**
```
E  |--3--|    G (5th)
A  |--3--|    C (root)
D  |--2--|    E (3rd)
```
*Ascending (5th → root → 3rd): G → C → E*  
*Descending (3rd → root → 5th): E → C → G*

**Note:** The pattern shape mirrors the high string arpeggio. Same chord tones (G, C, E), different octave, different strings.

**Expand it:**
- Open E string (fret 0) = E, the 3rd — you can anchor the pattern lower: E → G → C → E
- Create a longer sweep: E (E6) → G (E6, fret 3) → C (A5, fret 3) → E (D4, fret 2)

**Practice Protocol:**
1. Start from G (E string, fret 3) → C (A string, fret 3) → E (D string, fret 2)
2. Keep the fretted notes clean — the E string fret 3 requires the ring finger
3. Try sweep picking the ascending version (all downstrokes, fluid)
4. Try fingerpicking: thumb on E string, index on A, middle on D

**Mastery Test:**
- [ ] G → C → E → C → G on strings 6-5-4, clean at 80 BPM
- [ ] Can name each note without pause
- [ ] Sweep picking version sounds smooth, not choppy

**Unlocks:** Required for [C-CAP-L]

### [C-2L-S] Low String Scale Run
> *"Know the full terrain of the low ground. No stone unturned."*

**Type:** Technique  
**Requires:** [C-1L]

**The Pattern:**
```
E  |--0--1--3--|    E  F  G
A  |--0--2--3--|    A  B  C    ← Root (C) on fret 3
D  |--0--2--3--|    D  E  F
```

**Ascending:** E - F - G - A - B - C - D - E - F  *(strings 6 → 5 → 4, low fret to high fret)*  
**Descending:** F - E - D - C - B - A - G - F - E *(reverse)*

**Important:** When ascending, notice the root (C, string 5 fret 3) comes just before crossing to string 4. That root is a landmark — feel it every time you pass through it.

**Practice Protocol:**
1. Ascending only first. Say note names.
2. Descending only. Note: string crossing at fret 3 → fret 3 (A to E strings) requires care.
3. Combined ascending + descending loop.
4. Practice starting from the E string open, and also starting from D string open (both are valid entry points)
5. Target: 90 BPM (16th notes)

**Mastery Test:**
- [ ] Ascending + descending cleanly at 90 BPM
- [ ] Can begin the ascent on any note within the fragment
- [ ] Can identify the root (C) each time it passes

**Unlocks:** Required for [C-CAP-L]

---

### [C-2L-Q] Low String Sequence
> *"The low strings have patterns too. Heavy sequences shake the ground."*

**Type:** Technique  
**Requires:** [C-1L]

**Sequence A — Groups of 3 (ascending):**
```
E  F  G  |  F  G  A  |  G  A  B  |  A  B  C  |  B  C  D  |  C  D  E  |  D  E  F
```

**Sequence B — Diatonic 3rds (ascending):**
```
E - G  |  F - A  |  G - B  |  A - C  |  B - D  |  C - E
```

**Sequence C — Groups of 4 (ascending):**
```
E  F  G  A  |  F  G  A  B  |  G  A  B  C  |  A  B  C  D  |  B  C  D  E  |  C  D  E  F
```

**Note on string crossings:** Because the low strings span strings 6-5-4 and have 2-3 notes per string, sequences will sometimes change strings mid-group. This is good — it trains you to track where you are in the shape regardless of string.

**Practice Protocol:**
1. Same order as high strings: A first, then B, then C
2. Go slow enough that every note is clean and intentional
3. All three sequences, ascending AND descending
4. Once fluent, play Sequence A on low strings immediately followed by Sequence A on high strings — feel the connection

**Mastery Test:**
- [ ] All three sequences, ascending, at 80 BPM
- [ ] Sequence A descending at 80 BPM
- [ ] Can transition between sequences without stopping

**Unlocks:** Required for [C-CAP-L]

## Tier 3 — Advanced Techniques

### [C-3H-L] High String Legato
> *"The blade that moves without sound is the most dangerous. Let the notes flow without the pick."*

**Type:** Technique  
**Requires:** [C-2H-A], [C-2H-S], [C-2H-Q]

Legato means using hammer-ons and pull-offs to produce notes without picking every one. This creates a flowing, connected, vocal-like sound.

**Basic Legato Scale (high strings):**
```
G  |  0h2  (open → hammer fret 2)
B  |  0h1h3 (open → hammer 1 → hammer 3)
e  |  0h1h3 (open → hammer 1 → hammer 3)
```
*Descending uses pull-offs: 3p1p0*

**Legato Arpeggio:**
- Hammer from G (string 3, open) → pull off
- Play C (string 2, fret 1) with pick → hammer if possible
- Play E (string 1, open)
- Return with pull-offs

**Legato Sequence — Groups of 3 (ascending):**
- Use hammer-ons within a string, then pick the first note on the new string
- Example pattern on B string: pick B, hammer C, hammer D — then pick on e string

**Practice Protocol:**
1. Isolate hammer-ons: open → fret 2 on G string. Make it ring as loud as the picked note.
2. Isolate pull-offs: fret 3 → fret 1 → open on e string. Equal volume, equal clarity.
3. Legato scale ascending, then descending.
4. Legato Sequence A at slow tempo.
5. The goal is **volume equality** — hamimered/pulled notes must match the attack of picked notes.

**Mastery Test:**
- [ ] Legato scale (ascending + descending) at 80 BPM, all notes equal volume
- [ ] Legato groups-of-3 sequence ascending at 70 BPM
- [ ] The phrase sounds flowing and musical, not stuttered

**Unlocks:** Required for [C-CAP-H]

---

### [C-3L-L] Low String Legato
> *"Even the heavy strings can speak softly. A warrior controls all volumes."*

**Type:** Technique  
**Requires:** [C-2L-A], [C-2L-S], [C-2L-Q]

**Basic Legato Scale (low strings):**
```
E  |  0h1h3  (open → hammer 1 → hammer 3)
A  |  0h2h3  (open → hammer 2 → hammer 3)   ← Root lands on hammer-on to fret 3!
D  |  0h2h3  (open → hammer 2 → hammer 3)
```
*Descending: 3p2p0 / 3p2p0 / 3p1p0*

**Special note:** The root (C, string 5 fret 3) arrives via hammer-on in the ascending run. Make it land with authority — it should sound strong, not weak.

**Legato Arpeggio (low strings):**
- Pick G (E string fret 3) → Pull off to open... 
- Actually: Pick C (A string fret 3) → hammer or pull within the arpeggio pattern

**Practice Protocol:**
1. Hammer-on drill on each string independently
2. Pull-off drill on each string independently
3. Full legato scale ascending + descending
4. Pay special attention to string 5 — it has frets 0, 2, and 3, meaning two successive hammer-ons (0 → 2 → 3)
5. Legato Sequence A

**Mastery Test:**
- [ ] Legato scale ascending + descending on low strings at 80 BPM, all notes clear
- [ ] Root note (hammer to A string fret 3) lands as strong as a picked note
- [ ] Legato groups-of-3 ascending at 70 BPM

**Unlocks:** Required for [C-CAP-L]

## Tier 3 — Realm Capstones

### [C-CAP-H] High Realm Adept ⭐ CAPSTONE
> *"You have learned every weapon of the high strings. Now wield them freely."*

**Type:** Capstone  
**Requires:** [C-2H-A], [C-2H-S], [C-2H-Q], [C-3H-L]

The capstone is not a fixed exercise. It is a **free improvisation test** over the high strings, combining everything learned.

**The Challenge:**
Set a backing track or drone in C major. Improvise for **60 seconds** over the top 3 strings using:
- Arpeggio shapes (wherever musically appropriate)
- Scale runs (straight)
- Sequences (groups of 3, 4, diatonic 3rds)
- Legato phrases
- **Intentional musical choices** — not just running exercises

**Criteria — the judge asks:**
- [ ] Does it sound *musical*, not like scales?
- [ ] Are arpeggio tones landing on strong beats?
- [ ] Are there moments of rest (not just constant notes)?
- [ ] Can you spontaneously move between arpeggio and scale?
- [ ] Zero confusion — no moments of "where am I?"

**Bonus:** Play a **16-bar melody** over the high 3 strings from memory. It should tell a small story — tension, release, question, answer.

**What this unlocks:** [C-4-FS], [C-4-FA], [C-4-FQ] — but only when BOTH Realm Capstones are complete.

---

### [C-CAP-L] Low Realm Adept ⭐ CAPSTONE
> *"You have learned every weapon of the low strings. Now wield them freely."*

**Type:** Capstone  
**Requires:** [C-2L-A], [C-2L-S], [C-2L-Q], [C-3L-L]

**The Challenge:**
Same format as High Realm Adept — 60-second improvisation on a C major drone, but restricted to **strings 4-5-6 only.**

- Arpeggio lines rooted in the low strings (the bass voice of the shape)
- Scale runs along strings 6 → 5 → 4
- Sequences (all three learned)
- Legato phrases
- Musical phrasing — not endless notes

**Criteria:**
- [ ] Lines feel heavy, grounded, purposeful (the low strings have a different character)
- [ ] Root (C, string 5 fret 3) used as a landing point at phrase endings
- [ ] Arpeggios give a sense of harmony even without the upper strings
- [ ] Legato sections flow naturally into picked sections
- [ ] The shape "lives" under your fingers — zero searching

**Bonus:** Play a walking bass-line feel — quarter notes, mostly arpeggio tones, with passing scale tones, 8 bars. Like a jazz bassist outlining the C chord.

**What this unlocks:** [C-4-FS], [C-4-FA], [C-4-FQ] — but only when BOTH Realm Capstones are complete.

### [C-4-FS] Full Shape Scale Run
> *"The mountain climbed from base to peak. All six strings, one continuous motion."*

**Type:** Technique  
**Requires:** [C-CAP-H] AND [C-CAP-L]

**The Full Pattern (C major, all 6 strings, C shape position):**
```
e  |--0--1--3--|    E  F  G
B  |--0--1--3--|    B  C  D
G  |--0--2-----|    G  A
D  |--0--2--3--|    D  E  F
A  |--0--2--3--|    A  B  C    ← Root is here
E  |--0--1--3--|    E  F  G
```

**Ascending (low to high):** E-F-G-A-B-C-D-E-F-G-A-B-C-D-E-F-G  
*(Nearly 3 full octaves of C major within the shape)*

**Descending:** Reverse — G-F-E-D-C-B-A-G-F-E-D-C-B-A-G-F-E

**The critical crossing:** Moving from the low realm (string 4) into the high realm (string 3) is the seam. On the D string (string 4), the highest note is F (fret 3), then G string (string 3) starts on open G. This is an open-string pivot — practice it in isolation until it's seamless.

**Practice Protocol:**
1. Practice just the D → G string crossing: F (D4, fret 3) → G (G3, open). Both directions.
2. Full ascending run, slowly (60 BPM quarter notes)
3. Full descending
4. Continuous ascending + descending loop
5. Target: 100 BPM (16th notes)
6. Advanced: start on each degree of the scale (not just E or C)

**Mastery Test:**
- [ ] Full 3-octave run ascending + descending at 100 BPM
- [ ] D → G string crossing is invisible — no hiccup
- [ ] Can start the run from any note within the pattern

**Unlocks:** Required for [C-CAP-F]

### [C-4-FA] Full Shape Arpeggio
> *"Every chord tone, every string, one sweeping arc."*

**Type:** Technique  
**Requires:** [C-CAP-H] AND [C-CAP-L]

**The Full Arpeggio (strings 5 → 1, ascending root position):**
```
e  |--0--|    E (3rd)
B  |--1--|    C (root)
G  |--0--|    G (5th)
D  |--2--|    E (3rd)
A  |--3--|    C (root)    ← Start here (primary root)
```

**Ascending:** C → E → G → C → E  (root → 3rd → 5th → root → 3rd)  
**Descending:** E → C → G → E → C (3rd → root → 5th → 3rd → root)

*Note: String 6 (E open = E, the 3rd) can optionally be included as a launch note, creating a 6-string sweep.*

**Extended Option (all 6 strings):**
```
e  |--0--|    E (3rd)
B  |--1--|    C (root)
G  |--0--|    G (5th)
D  |--2--|    E (3rd)
A  |--3--|    C (root)
E  |--0--|    E (3rd) ← optional low anchor
```
This is a full 6-string sweep from E (3rd) → C → E → G → C → E

**Picking technique:**
- Sweep picking: continuous downstroke ascending, continuous upstroke descending
- Alternate picking: for control and precision
- Fingerpicking: beautiful arpeggiated texture (p-i-m-a pattern or variations)

**Practice Protocol:**
1. Sweep ascending only: C → E → G → C → E (strings 5 → 1)
2. Sweep descending only: E → C → G → E → C (strings 1 → 5)
3. Combined ascending + descending in one fluid motion
4. Add string 6 (open E) as a low anchor
5. Try all three picking approaches

**Mastery Test:**
- [ ] Full arpeggio ascending + descending, sweep picked, at 90 BPM (16th notes), clean
- [ ] Can arpeggiate the shape in multiple rhythmic feels (8th notes, 8th note triplets, 16th notes)
- [ ] Fingerpicked version sounds controlled and even

**Unlocks:** Required for [C-CAP-F]

### [C-4-FQ] Full Shape Sequence
> *"Sequences across the full shape — the territory speaks in patterns, from root to peak."*

**Type:** Technique  
**Requires:** [C-CAP-H] AND [C-CAP-L]

Now sequences span ALL 6 strings, crossing the realm boundary freely.

**Full-Shape Sequence A — Groups of 3 (ascending):**
```
E-F-G | F-G-A | G-A-B | A-B-C | B-C-D | C-D-E | D-E-F | E-F-G ...
```
*(This runs across all 6 strings — when a group crosses a string boundary, follow the fingering naturally)*

**Full-Shape Sequence B — Diatonic 3rds (ascending, all strings):**
```
E-G | F-A | G-B | A-C | B-D | C-E | D-F | E-G ...
```

**Full-Shape Sequence C — Groups of 4:**
```
E-F-G-A | F-G-A-B | G-A-B-C | A-B-C-D | B-C-D-E | C-D-E-F | D-E-F-G
```

**The Realm Crossing Challenge:**
Sequences frequently straddle the D-G string (strings 4-3) boundary. This is where the two realms meet. The seam should be *invisible* in your sequences.

**Practice Protocol:**
1. Sequence A ascending full shape, slowly
2. Sequence A descending
3. Sequence B ascending + descending
4. Sequence C ascending + descending
5. Chain sequences: A ascending → B descending → back to A. Seamless transitions.

**Mastery Test:**
- [ ] Sequence A (groups of 3), ascending and descending, full 6 strings, at 80 BPM
- [ ] Sequence B (3rds), ascending, at 80 BPM

### [C-5-MV] Shape Traveler
> *"The C shape is not tied to any key. It is a portable fortress. Move it anywhere."*

**Type:** Knowledge + Technique  
**Requires:** [C-CAP-F]

The C shape is **moveable**. When you barre the neck and shift the whole shape up the fretboard, the key changes but the shape stays the same. This is the power of CAGED.

**The Logic:**
The primary root of the C shape lives on **string 5** (the A string). Wherever you barre, the root is defined by whatever note is on string 5 at that fret.

**Root positions on the A string:**
```
Fret 0 = A  → A major (open A-string C shape... advanced, but the concept is there)
Fret 2 = B  → B major
Fret 3 = C  → C major (our home position)
Fret 5 = D  → D major
Fret 7 = E  → E major
Fret 8 = F  → F major
Fret 10 = G → G major
```

**Practice Protocol:**
1. Play the C chord (open position). Notice the root on string 5 at fret 3.
2. Move the *shape* up 2 frets (barre at fret 2, shape above it). What key are you in? (B major — but this partial barre is advanced)
3. The cleaner exercise: **take just the arpeggio pattern** (string 5 → 4 → 3 → 2 → 1) and move it to fret 5 (D root). Play the D major arpeggio in C shape.
4. Move to fret 7 (E root). Play E major arpeggio in C shape.
5. Move to fret 8 (F root). Play F major arpeggio in C shape.
6. **Full scale:** move the entire scale pattern to each new root. The finger pattern stays the same — only position changes.

**The key insight to internalize:**
> The shape is the same. The key is wherever your root lands. You are not learning new shapes — you are learning that one shape speaks every language.

**Mastery Test:**
- [ ] Can play the C-shape arpeggio in D, E, F, and G without hesitation
- [ ] Can play the C-shape scale run in at least 3 different keys
- [ ] Given a key, can instantly place the C shape at the correct fret
- [ ] Can explain *why* the shape is moveable (root on string 5 defines the key)

**Unlocks:** Required for [C-MASTER]

### [C-5-CH] Chord Alchemist
> *"From one shape, many colors. The root is just the beginning."*

**Type:** Knowledge + Technique  
**Requires:** [C-CAP-F]

The C major shape is a vessel. By adding, removing, or shifting individual notes, you can create a family of chords — all rooted in the same shape geography.

**Chord Variations within the C shape (open position):**

| Chord Name | Voicing | Notes | What changed |
|---|---|---|---|
| C major | x32010 | C E G C E | Baseline |
| Cmaj7 | x32000 | C E G B E | Lift index finger (B string rings open) |
| C7 | x32310 | C E Bb C E | Add pinky on G string fret 3 (Bb) |
| Csus2 | x30010 | C G C D E | Lift middle finger (D string open, adds D) |
| Csus4 | x33010 | C F G C E | Middle finger to D string fret 3 (F) |
| Cadd9 | x32030 | C E G D E | Add ring on B string fret 3 (D) |
| Am/C | x32210 | C E A C E | Shift fingering — borrowing the Am shape |
| C6 | x32210 | C E A C E | Same as Am/C — C major 6th voicing |

**Practice Protocol:**
1. Learn each chord variation. Confirm every note rings.
2. Name the notes in each variation aloud.
3. Practice moving between C major and Cmaj7 smoothly — only one finger change.
4. Practice C major → C7 → back. (This is the classic blues move.)
5. Practice C → Csus4 → C → Csus2 → C (suspended resolution).

**The Listening Challenge:**
Play each chord and describe what you hear — "darker," "brighter," "unresolved," "dreamy." Start building emotional vocabulary for chord colors.

**Mastery Test:**
- [ ] Can play all 8 chord variations listed above without hesitation
- [ ] Can name the notes in at least 4 of them from memory
- [ ] Can describe the emotional character of each with at least one word
- [ ] Can move between any two of them cleanly in a chord progression

**Unlocks:** Required for [C-MASTER]
